# Pandas Data Analysis Practice Notebook

## Overview

This repository contains a Jupyter Notebook (`pandas.ipynb`) demonstrating the fundamentals of the Python **Pandas** library for data manipulation and analysis.

The notebook covers essential Pandas operations including DataFrame creation, data exploration, filtering, data cleaning, aggregation, and merging datasets.

## Topics Covered

### 1. DataFrame Creation

* Creating DataFrames from lists
* Creating DataFrames from dictionaries
* Understanding DataFrame structure

### 2. Understanding DataFrames

* `head()`
* `tail()`
* `shape`
* `columns`
* `rename()`
* `info()`
* `describe()`

### 3. Save and Load Data from CSV

* Exporting DataFrames using `to_csv()`
* Importing CSV files using `read_csv()`

### 4. Row and Column Selection

* Selecting columns
* Selecting rows
* Using indexing techniques

### 5. Filtering DataFrames

* Conditional filtering
* Multiple conditions
* Data extraction based on criteria

### 6. Row and Column Operations

* Adding new columns
* Updating existing values
* Deleting rows and columns

### 7. Working with Date Values

* Date conversion
* Date-based operations
* Date formatting

### 8. Handling Missing Values

* Detecting missing values
* Filling missing values
* Removing missing data

### 9. Aggregation and GroupBy

* Summarizing data
* Aggregate functions
* GroupBy operations

### 10. Concatenation and Merge (Joins)

* Concatenating DataFrames
* Inner Join
* Left Join
* Right Join
* Outer Join

## Prerequisites

Install Pandas before running the notebook:

```bash
pip install pandas
```

## Running the Notebook

1. Clone the repository.
2. Install required dependencies.
3. Launch Jupyter Notebook:

```bash
jupyter notebook
```

4. Open `pandas.ipynb`.
5. Run the cells sequentially.

## Learning Outcomes

After completing this notebook, you will be able to:

* Create and manage Pandas DataFrames.
* Explore and inspect datasets efficiently.
* Filter and manipulate data.
* Handle missing values.
* Perform aggregation and grouping.
* Work with CSV files.
* Merge and concatenate datasets for analysis.
